    Live in this prototype
    • Seeded with six entries; stock, average cost and running balances are all computed live.
    • Buy and Sell write to the shared ledger — every screen updates, with a toast confirmation.
    • Selling more than the stock on hand disables Save and names the amount available.
    Added by the real build
    • Node/Express API on MongoDB; totals computed server-side, 422 on over-sell.
    • JWT issued for the mani credential; every other route requires it.
    • Flutter client holds the token in secure storage; data persists across devices.
